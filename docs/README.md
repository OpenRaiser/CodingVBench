# CodingVBench project page

Static homepage (NeurCo-style) for GitHub Pages.

## Local preview

```bash
cd docs
python3 -m http.server 8765
# open http://127.0.0.1:8765/
```

## GitHub Pages

Enable Pages from `/docs` on `main` (same pattern as [NeurCo](https://openraiser.github.io/NeurCo/)).

Live URL once published: `https://openraiser.github.io/CodingVBench/`
